# ai-bajan-tourism-directory

AI Bajan — a Barbados tourism discovery platform and business directory with searchable listings, an AI travel assistant (RAG chatbot), advertising placements and an admin dashboard.

## Repository layout

| Folder | Status | Description |
| --- | --- | --- |
| [`client/`](client/) | Built | Public website — React + Vite SPA. Runs standalone on demo data; see [client/README.md](client/README.md). |
| `admin/` | Planned | Separate admin dashboard frontend. |
| `server/` | Planned | Node.js API: listings, search, RAG chatbot (OpenAI), forms. |

Each folder is an independent project with its own dependencies and deployment.
