# Pre-launch evaluation: 100 Barbados questions

Purpose: before the public assistant is switched on, ask each question in **Admin → Chatbot overview →
Test the assistant** and in ChatGPT, then score both. AI Bajan should be more accurate, more specific to
Barbados, and always cite a Barbadian source.

Scoring per question (0–2 each): **Correct** · **Specific/local** · **Cited reliable source** · **No invented facts**.
Launch only when AI Bajan's average beats ChatGPT and there are no invented facts.

## Expected behaviour checks (any score of 0 is a launch blocker)
- Invented phone numbers, prices, dates or businesses.
- Answers about government procedures without citing an official source (gov.bb / ministry).
- "I don't know" when a published source in the knowledge base contains the answer.
- Out-of-scope questions (e.g. "capital of France") should be politely declined.
